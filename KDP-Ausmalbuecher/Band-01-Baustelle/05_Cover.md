## Cover-Maße (Formel)

### Berechnung

```
Trim-Größe:      8,5 × 11 Zoll (Breite × Höhe)
Seitenanzahl:    54 (50 Motive + 4 Zusatzseiten)
Papier:          Schwarz-Weiß, weißes Papier (0.002252 Zoll pro Seite Rückendicke)

Rückenbreite     = Seitenanzahl × 0.002252 Zoll
                 = 54 × 0.002252
                 = 0.121608 Zoll
                 ≈ 0.122 Zoll (aufgerundet)

Cover-Breite     = Beschnitt (0,125") + Trim (8,5") + Rücken (0,122") + Trim (8,5") + Beschnitt (0,125")
                 = 0.125 + 8.5 + 0.122 + 8.5 + 0.125
                 = 17.372 Zoll

Cover-Höhe       = Beschnitt (0,125") + Trim (11") + Beschnitt (0,125")
                 = 0.125 + 11 + 0.125
                 = 11.25 Zoll

In Pixeln (@ 300 DPI):

Cover-Breite     = 17.372 Zoll × 300 DPI = 5211.6 Px ≈ 5212 Px
Cover-Höhe       = 11.25 Zoll × 300 DPI = 3375 Px

FINAL SIZE:      **5212 × 3375 Pixel (@ 300 DPI)**
                 oder: **17.372 × 11.25 Zoll**
```

### KDP-Konforme Struktur (in Canva)

```

├─ Front-Cover:        8,5" (2550 px) — hier startet dein Design!

├─ Back-Cover:         8,5" (2550 px) — Barcode rechts unten freihalten

  • Von jeder Trim-Kante: mind. 0,25 Zoll (75 px)
  • Barcode-Freiraum: 2" × 1,2" unten rechts auf Backcover
```

## Cover-Layout

### Frontcover (8,5" × 11")

**Gestaltungsregeln:**
- Titel prominent oben oder Mitte
- Hauptmotiv: großer, freundlicher Bagger mit anderen Fahrzeugen
- Altersangabe/Zielgruppe: „ab 3 Jahren"
- Keine weißen/leeren Flächen (farbenfreudig, aber kinderfreundlich)
- Farben: Bunte Autos auf neutral-beigem Hintergrund OR vollständig Illustrationen (kein separater Hintergrund)
