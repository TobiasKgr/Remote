# Auftrag für Claude (Claude Desktop, mit aktiviertem Canva-Connector)

**Verwendung:** Diese Datei komplett in einen neuen Chat in Claude Desktop
einfügen (oder als Anhang hochladen) — in einem Chat, in dem der
**Canva-Connector aktiviert** ist. Claude generiert dann die Bilder direkt
über Canva.

---

## Aufgabe

Erzeuge mit dem Canva-Connector **50 Ausmalbilder** (schwarz-weiß Line-Art)
für ein Kinder-Ausmalbuch namens „Mein Baustellen-Malbuch". Für jedes Motiv
unten:

1. Nutze die Canva-Bildgenerierung (Magic Media / `generate-design`) mit dem
   exakten **Prompt** in Spalte „Prompt"
2. Exportiere das Ergebnis als **PNG, 300 DPI**
3. Benenne die Datei **exakt** wie in Spalte „Dateiname" angegeben
4. Wiederhole für alle 50 Motive + die 2 Cover-Motive am Ende
5. Fasse am Ende zusammen, welche Dateien erzeugt wurden und stelle sie zum
   Download bereit

**Bildstil (gilt für alle 50 Motive, ist bereits in jedem Prompt enthalten):**
Dicke schwarze Konturen, einfache Formen, schwarz-weiß Line-Art, keine
Schattierung, keine Graustufen, weißer Hintergrund, kinderfreundlich.

**Wichtig:** Keine Farbe, keine Grauverläufe — nur klare schwarze Linien auf
weißem Grund, damit die Bilder zum Ausmalen geeignet sind.
